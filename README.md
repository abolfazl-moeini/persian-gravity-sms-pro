# پیامک گرویتی فرم — نسخهٔ ایران‌پیامک

افزونهٔ وردپرس برای ارسال پیامک از طریق **Gravity Forms**، با پشتیبانی از درگاه **ایران‌پیامک**.

## دربارهٔ این پروژه

این مخزن بر پایهٔ افزونهٔ [persian-gravity-sms-pro](https://gravityforms.ir/9975/) تهیه شده است؛ یک **کپی / fork** از همان پلاگین با هدف گسترش درگاه‌های پیامکی.

**تغییر اصلی نسبت به نسخهٔ پایه:** افزودن درگاه **ایران‌پیامک** (`includes/gateways/iranpayamak.php`).

در آینده ممکن است بهبودها و قابلیت‌های دیگری نیز به این مخزن اضافه شود.

## پیش‌نیازها

- وردپرس 5.0 یا بالاتر
- افزونهٔ [Gravity Forms](https://www.gravityforms.com/) نسخهٔ 1.9.10 یا بالاتر
- حساب کاربری و **کلید API** از [ایران‌پیامک](https://iranpayamak.com)

## نصب

1. پوشهٔ پروژه را در `wp-content/plugins/` کپی کنید.
2. از منوی **افزونه‌ها** در وردپرس، افزونه را فعال کنید.
3. به **تنظیمات Gravity Forms → SMS Settings** بروید.
4. درگاه **ایران پیامک** را انتخاب کنید.
5. **کلید API** و **شماره خط فرستنده** را وارد و ذخیره کنید.

## پیکربندی درگاه ایران‌پیامک

| فیلد | توضیح |
|------|--------|
| کلید API | کلید دریافتی از پنل ایران‌پیامک |
| Sender (From) | شماره خط اختصاصی، مثلاً `50002178584000` |

پس از ذخیره، در صورت فعال بودن گزینهٔ نمایش موجودی، اعتبار پیامک از API خوانده و نمایش داده می‌شود.

## قابلیت‌ها

- ارسال پیامک به مدیر و کاربر پس از ثبت فرم
- تایید شماره موبایل قبل از ثبت
- منطق شرطی برای ارسال پیامک
- شورتکدهای فیلدهای Gravity Forms در متن پیامک
- یکپارچگی با درگاه‌های پرداخت (ارسال پس از پرداخت موفق)
- ارسال گروهی و گزارش پیامک‌های ارسال‌شده

## درگاه‌های پشتیبانی‌شده

| درگاه | وضعیت |
|-------|--------|
| ایران‌پیامک | افزوده‌شده در این مخزن |
| ملی‌پیامک | از نسخهٔ پایه |
| کاوه‌نگار | از نسخهٔ پایه |

## ساختار درگاه جدید

درگاه‌ها به‌صورت خودکار از پوشهٔ `includes/gateways/` بارگذاری می‌شوند. هر فایل درگاه باید کلاسی با الگوی `GFHANNANSMS_Pro_{NAME}` و متدهای `name()`، `options()`، `credit()` و `process()` داشته باشد.
